# Grok scout guides

Reference files for the WW2 Dispatches Grok scout. Grok reads these; it saves its weekly reports to scout/.

* media-guide.md: photo and film sources and rules
* scout-report-format.md: the exact report template and self check
* covered-events.md: planned big dates, plus the link to the live dispatch log
* project-instructions.md: the text pasted into the Grok project instructions box (paste only, Grok does not read this file)

Edit these here (or ask Claude), not in scout/.
